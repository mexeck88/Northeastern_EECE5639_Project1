\section*{Abstract}
This report details the implementation and analysis of motion detection algorithms using temporal derivatives. The primary objective was to detect moving objects in video sequences by analyzing pixel intensity changes over time. I implemented a pipeline consisting of grayscale conversion, temporal differentiation (using both simple finite differences and Gaussian derivative operators), spatial filtering (box and Gaussian), and adaptive thresholding to generate binary motion masks. The algorithms were tested on three datasets: \textit{Office}, \textit{Red Chair}, and \textit{Crossing}. 

Our analysis highlights the critical need to balance spatial and temporal filtering to mitigate both sensor noise and "ghosting" artifacts. I found that the optimal configuration across all datasets was a Gaussian derivative with $\sigma_t=0.25$ combined with spatial Gaussian smoothing of $\sigma_s=0.25$. This combination effectively suppressed noise without introducing significant ghosting, which was identified as a major issue in the \textit{Office} and \textit{Red Chair} datasets due to their lower frame capture rates. In the \textit{Crossing} dataset, ghosting only became problematic at higher temporal scales ($\sigma_t \ge 1.0$).

\section{Description of Algorithms}
The motion detection system processes video sequences frame-by-frame. The core pipeline is described below:

\subsection{Preprocessing}
Each input video frame $I(x, y, t)$ is first converted from RGB color space to grayscale to simplify intensity analysis. In order to perform this in python, I utilized the \textbf{cv2} package's (OpenCV \cite{opencv_library}) \textbf{cvtColor} function:

\begin{lstlisting}[language=Python, caption=Python Example]
def load_frames_and_grayscale(dir_path):

    frames = []
    print("[i] Loading frames from directory: ", dir_path)

    files = sorted(os.listdir(dir_path))
    
    for filename in tqdm.tqdm(files, desc="Frames to Grayscale"):
        if filename.endswith(".jpg"):
            frame = cv2.imread(os.path.join(dir_path, filename))
            gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY).astype(np.float32)
            frames.append(gray)                                
    return np.array(frames) # Shape: (Time, Height, Width)
\end{lstlisting}

\subsection{Temporal Differentiation}
To detect motion, I compute the temporal derivative $\frac{\partial I}{\partial t}$ at each pixel. Two methods were implemented:

\subsubsection{Simple Difference}
A symmetric finite difference operator is applied:
\begin{equation}
    \frac{\partial I}{\partial t} \approx \frac{I(t+1) - I(t-1)}{2}
\end{equation}
This is implemented by convolving the temporal signal with the kernel $[-0.5, 0, 0.5]$. While computationally efficient, this method is highly sensitive to noise.

\begin{lstlisting}[language=Python, caption=Simple Difference Operator]
def apply_simple_diff_operator(frames):
    simple_kernel = np.array([-0.5, 0, 0.5])
    deriv_simple = scipy.ndimage.convolve1d(frames, simple_kernel, axis=0)
    # Trim the edges
    deriv_simple = deriv_simple[1:-1]
    return deriv_simple
\end{lstlisting}

\subsubsection{Gaussian Derivative ($G_t'$)}
To improve robustness, I smooth the temporal signal with a Gaussian function $G(t; \sigma_t)$ before differentiation. This is implemented using the \textit{SciPy} library \cite{scipy_library}. This is equivalent to convolving with the derivative of a Gaussian kernel $G'(t; \sigma_t)$. 
\begin{equation} \label{eq:gauss_deriv}
    \frac{\partial I}{\partial t}_{smooth} = I(t) * \frac{\partial G}{\partial t}
\end{equation}
The smoothing reduces high-frequency noise, making the derivative more indicative of structural motion. I tested temporal scales $\sigma_t \in \{0.25, 0.5, 1.0\}$.

\begin{lstlisting}[language=Python, caption=Gaussian Derivative Operator]
def apply_gaussian_diff_operator(frames, std_dev):
    gaussian_res = scipy.ndimage.gaussian_filter1d(frames, sigma=std_dev, axis=0, order=1)
    # Trim the edges
    trim_ammount = int(4 * std_dev)
    gaussian_res = gaussian_res[trim_ammount:-trim_ammount]
    return gaussian_res
\end{lstlisting}

\subsection{Spatial Filtering}
Before computing the temporal derivative, spatial smoothing is applied to each frame to reduce sensor noise and small texture variations. I compared two spatial filters:
\begin{enumerate}
    \item \textbf{Box Filter}: Computes the local mean within a $k \times k$ window ($k \in \{3, 5\}$).
    \item \textbf{Gaussian Filter}: Convolves the image with a 2D Gaussian kernel $G(x, y; \sigma_s)$, which provides better preservation of edges compared to the box filter. I tested $\sigma_s \in \{0.25, 0.5, 1.0\}$.
\end{enumerate}

\begin{lstlisting}[language=Python, caption=Spatial Filtering]
def apply_2d_spatial_filtering(frames, std_dev, kernel_size, filter_type='gaussian'):
    if filter_type == 'gaussian':
        kernel = cv2.getGaussianKernel(kernel_size, std_dev)
        kernel = kernel @ kernel.T
    elif filter_type == 'box':
        kernel = np.ones((kernel_size, kernel_size), np.float32) / (kernel_size * kernel_size)
    
    filtered_img = cv2.filter2D(src=frames, ddepth=-1, kernel=kernel)
    return filtered_img
\end{lstlisting}

\subsection{Thresholding}
A binary motion mask $M(x, y, t)$ is generated by thresholding the absolute value of the temporal derivative:
\begin{equation}
    M(x, y, t) = \begin{cases} 
      1 & \text{if } \left| \frac{\partial I}{\partial t} \right| > T \\
      0 & \text{otherwise}
   \end{cases}
\end{equation}
I used an adaptive threshold $T = k \cdot \sigma_{noise}$, where $\sigma_{noise}$ is the standard deviation of the temporal derivatives across the frame, assuming the background noise distribution is Gaussian. I set $k=3.0$ for all experiments.

\begin{lstlisting}[language=Python, caption=Adaptive Thresholding]
def get_adaptive_threshold(derivatives, k=3.0):
    noise_sigma = np.std(derivatives)
    return k * noise_sigma

def form_binary_mask(derivatives, threshold):
    mask = np.abs(derivatives) > threshold
    return mask
\end{lstlisting}

\subsection{Visualization}
Finally, the binary motion mask $M(x, y, t)$ is combined with the original color frame to visualize the detected motion. The mask is overlaid (e.g., in green or red) on the original image to clearly distinguish moving objects from the background.

\section{Experiments and Parameters}
The algorithms were evaluated on three datasets exhibiting different motion characteristics:
\begin{itemize}
    \item \textbf{Office}: Indoor scene with a person walking. Medium frame rate.
    \item \textbf{Red Chair}: Chair moved into frame. Low frame rate.
    \item \textbf{Crossing} (EnterExitCrossingPaths2cor): Surveillance with many moving individuals in frame. Standard frame rate.
\end{itemize}

\subsection{Parameter Sweeps}
Two primary experiments were conducted to analyze the impact of filter parameters:

\subsubsection{Experiment 1: Spatial Box Filter}
I fixed the spatial smoothing to a Box Filter of size $3 \times 3$ and $5 \times 5$. For each size, I compared the Simple Temporal Difference against Gaussian Temporal Derivatives with $\sigma_t \in \{0.25, 0.5, 1.0\}$.

\subsubsection{Experiment 2: Spatial Gaussian Filter}
I used a Gaussian spatial filter with varying $\sigma_s \in \{0.25, 0.5, 1.0\}$ (kernel size fixed at $5 \times 5$). Similar to Exp. 1, I compared Simple Temporal Difference and Gaussian Temporal Derivatives across the same $\sigma_t$ range.

\section{Observations and Results}

\subsection{Effect of Temporal Smoothing ($\sigma_t$)}
The Simple Difference operator ($[-0.5, 0, 0.5]$) proved to be very sensitive to noise, often resulting in "speckled" motion masks even in static regions (false positives). Increasing $\sigma_t$ in the Gaussian derivative significantly reduced this noise. 

However, temporal smoothing introduced a trade-off with \textit{ghosting}.
\begin{itemize}
    \item \textbf{Low $\sigma_t$ (0.25)}: Provided the best balance. It effectively reduced noise while maintaining sharp temporal boundaries.
    \item \textbf{High $\sigma_t$ (1.0)}: Caused significant ghosting. This was particularly severe in the \textit{Office} and \textit{Red Chair} datasets due to their slow frame capture rate; the object moved significantly between frames, and smoothing blended distinct positions, creating wide, inaccurate masks. In the \textit{Crossing} dataset, ghosting was less pronounced at lower $\sigma_t$ but became an issue at $\sigma_t=1.0$.
\end{itemize}

\subsection{Effect of Spatial Smoothing}
Spatial smoothing was crucial for suppressing texture noise.
\begin{itemize}
    \item \textbf{Box Filter}: Effective at removing noise but tended to blur object boundaries, making the detected shapes blocky.
    \item \textbf{Gaussian Filter}: Provided a better trade-off. Specifically, $\sigma_s=0.25$ combined with $\sigma_t=0.25$ yielded the cleanest results across all datasets.
\end{itemize}

\subsection{Effect of Threshold Parameter ($k$)}
The adaptive threshold $T = k \cdot \sigma_{noise}$ plays a crucial role in separating motion from background noise.
\begin{itemize}
    \item \textbf{$k=1$}: Selecting a low threshold captures subtle movements but is highly susceptible to sensor noise, resulting in a "noisy" mask with many false positives scattered across the background.
    \item \textbf{$k=3$}: Increasing $k$ to 3 raises the bar for detection. This successfully suppresses the background noise, leaving only the significant motion regions corresponding to the moving object.
\end{itemize}

This trade-off is illustrated in Fig. \ref{fig:k_comparison}, where $k=1$ shows granular noise in the background, while $k=3$ produces a clean segmentation of the walking person.

\subsection{Ghosting and Frame Rate Analysis}
The "ghosting" artifact, where the moving object appears significantly larger than its actual size or leaves a trail, is exacerbated by two factors: excessive spatial/temporal smoothing and low video frame rates. 

In the \textit{Red Chair} dataset, which has a notably low frame rate, the object undergoes large displacements between consecutive frames. When strong spatial smoothing (high $\sigma_s$) is applied, the boundaries of the object at time $t$ and $t+1$ are blurred and merged, creating a wide "ghost" region in the difference image.

Figure \ref{fig:ghosting_analysis} demonstrates this effect. As the spatial Gaussian $\sigma_s$ increases, the detected mask expands well beyond the actual chair, losing the object's precise shape. This confirms that for low-frame-rate, high-displacement videos, minimal smoothing is essential to avoid ghosting.

\section{Conclusions}
I successfully implemented a motion detection system based on temporal differentiation. Our experiments verified that balancing spatial and temporal filtering is key to robust detection. 

The optimal configuration for all three datasets was found to be a minimal Gaussian smoothing: \textbf{$\sigma_s=0.25$ (Spatial) and $\sigma_t=0.25$ (Temporal)}. 

I observed that "ghosting" artifacts are heavily influenced by the video frame rate. The \textit{Office} and \textit{Red Chair} datasets, having lower frame rates, were highly susceptible to ghosting even with moderate temporal smoothing. In contrast, the \textit{Crossing} dataset only exhibited ghosting at high smoothing levels ($\sigma_t \ge 1.0$). Therefore, for low-frame-rate surveillance, minimal temporal smoothing is preferred to maintain object localization accuracy.

Future improvements could include background modeling (e.g., Mixture of Gaussians) to handle stationary changes (like lighting) and morphological operations (dilation/erosion) to fill gaps in the detected motion masks.
